    How to use GeoInfer

    1. Choose an image. Pick a scene from the list. To use your own, open Add images, drop a GeoTIFF, check it, then add it as a scene.
    2. Select an area. Drag a rectangle, click a polygon (double-click to finish), use the current view, or type coordinates.
    3. Run. Choose the sensor model and priority, then Find buildings. Optical is the most accurate; SAR works through cloud; fused combines both.
    4. Results. Outlines appear on the map. Click a building for its area and confidence, and download the GeoJSON or the mask.

    What images work

    GeoTIFFs with a map projection and about 0.5 m pixels. Optical images need 4 bands (R, G, B, NIR); SAR images 4 bands in dB. Add images checks each file and can reproject it for you. Everything stays on this computer.
